Welcome to the Digital Grimoire

This tome records working code as spells. Shell commands and Python scripts are spells: short words that bend the system to your will. C and Assembly programs are artifacts: heavier objects, forged by a compiler, that work closer to the metal.

Every page follows the same shape: the Spell Name, its Mana Cost and Risk, the Incantation (the code), the Invocation (how to run it), and the Effect (what it really does, in plain words first). The lore is decoration. The code is real.

Choose a school below and begin reading.

Reading the Runes

■□□□□ 1
Cantrip. A single command.
■■□□□ 2
Minor. Flags, pipes, or a tiny script.
■■■□□ 3
Ritual. Control flow, error handling, OS calls.
■■■■□ 4
Greater. Concurrency, memory, protocols.
■■■■■ 5
Archmage. Assembly and syscall-level work.
SAFE
Read-only. Leaves no mark.
VOLATILE
Changes files or opens ports. Reversible.
FORBIDDEN
Needs root or can destroy data. Cast with care.
