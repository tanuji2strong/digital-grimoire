import sys
from pathlib import Path


def bulk_rename(folder, prefix, apply=False):
    files = sorted(p for p in Path(folder).iterdir() if p.is_file())
    for i, old in enumerate(files, start=1):
        new = old.with_name(f"{prefix}-{i:03d}{old.suffix.lower()}")
        if new.exists() and new != old:
            print(f"SKIP {old.name}: {new.name} already exists")
            continue
        print(f"{old.name} -> {new.name}")
        if apply:
            old.rename(new)
    if not apply:
        print("Dry run only. Add --apply to rename for real.")


if __name__ == "__main__":
    if len(sys.argv) < 3:
        sys.exit("usage: python bulk_rename.py <folder> <prefix> [--apply]")
    bulk_rename(sys.argv[1], sys.argv[2], "--apply" in sys.argv[3:])

Effect

In plain terms: Renames every file in a folder to <prefix>-001, <prefix>-002, and so on in sorted order, keeps each extension in lowercase, and only previews the changes unless --apply is given.

The familiar lines up the scrolls in a folder and calls out a new name for each. It only speaks the names until you grant it --apply.

sorted() orders the regular files and leaves out subfolders. enumerate(files, start=1) supplies the number, and {i:03d} pads it to three digits. new.exists() skips any file whose target name is taken, so nothing is overwritten. old.rename(new) runs only when --apply is present.

Side Effects

  • The original names are not saved. Keep the printed list if you may need to undo the renames.
  • The sort is case-sensitive, not strictly alphabetical: Zed.png comes before beach.png.
  • Hidden files are renamed too and take up numbers. On macOS, .DS_Store can become trip-001, with no extension.
  • Only the last extension is kept: archive.tar.GZ becomes trip-001.gz.
  • A skipped file keeps its old name and its number goes unused. Subfolders are not entered.
  • The preview can differ from the real run. A file shown as SKIP may still be renamed under --apply if an earlier rename frees the target name.
  • On a case-insensitive file system (the macOS default), a case-only change such as trip-001.TXT to trip-001.txt is skipped as already existing.
  • Backfires with a traceback if the folder does not exist or the prefix contains /. --apply must come after the folder and prefix.
